# 임시 SaaS 프론트

빌드 단계 없는 HTML/CSS/JavaScript 프론트다. 제품 인계를 위한 실제 로컬 실행 UI이며 운영용 인증·DB 연동은 없다. 현재 구현 상태와 Django·프론트·PO 후속 작업은 [루트 README](../README.md)를 기준으로 한다.

```bash
python -m agent.console --port 4174
```

- `/#overview`: 실제 실행 진입 + 50개 타일 UI 재생. 실제 50개 실행이 아니다.
- `/#personas`: 기능·과업·타겟 확인, 실제 페르소나 실행/카드/팝업/종료 이유/추가 질문.
- `/#report`: 완료 리포트, 당시 근거 bbox·확대, 개선 목업, Markdown/PDF 다운로드.
- `/#projects`, `/#settings`: 브라우저 localStorage 기반 임시 등록/설정.
- `/#connect`: 로컬 반찬로드 브라우저 연결·수동 조작·현재 화면 기록. 쇼핑몰 4173과 별도 Skyvern 설치 필요.
- `/#admin`: 내부 운영 화면의 UI 구분만 제공. 관리자 권한 검사는 미구현.

실행 정보·근거·리포트는 `/api/personas/*` 및 `/api/artifacts/*`를 사용한다. 2명짜리 기존 샘플 실행은 `/api/runs`를 사용하며 페르소나 리포트와 다른 실행 경로다. 운영 이관 시 두 경로의 스키마를 통합해야 한다.

프론트의 일부 상태/자료는 로컬 저장소에 남는다. 예전에 등록한 프로젝트 목록은 사용자 브라우저에만 저장되므로 새로운 서버 프로젝트 목록과 다를 수 있다. 실제 외부 사이트 실행을 지원하는 것으로 해석하지 않는다.
