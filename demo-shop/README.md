# 반찬로드 테스트 프론트

빌드 도구 없이 HTML·CSS·JavaScript로 만든 로컬 반찬 구독 쇼핑몰이다. 랜딩·상품 상세·장바구니·강제 가입·배송 정보·모의 주문 완료·브랜드 소개를 제공한다. 장바구니와 모의 주문은 브라우저 세션에만 저장된다.

## 직접 열기

프로젝트 루트, 설치된 Python 환경에서:

```bash
python -m agent.shop --port 4173
```

- 테스트 조건 선택: `http://127.0.0.1:4173/lab`
- 개선 버전: `http://127.0.0.1:4173/?variant=fixed&case=all`
- 문제 버전: `http://127.0.0.1:4173/?variant=problem&case=all`

`/lab`은 평가자가 쓰는 제어 화면이다. 에이전트는 각 랜딩 링크부터 시작한다. 외부 이미지·폰트 서버에 접근하지 않도록 자산을 로컬에 저장했다. 테스트 환경에서 띄운 임시 서버는 종료할 수 있으므로 필요하면 위 명령으로 다시 시작한다.

## 케이스

| case | 문제 버전 | 개선 버전 |
|---|---|---|
| signup | 주문 전 8개 정보 필드와 동의가 필요한 가입 화면 | 비회원 배송 정보 입력으로 진행 |
| fee | 상품·장바구니에서는 배송비 미노출, 배송 화면에서 3,500원 추가 | 상품·장바구니부터 배송비와 총액 노출 |
| cta | 긴 상품 설명 아래에 담기 버튼 | 상품 주요 정보 바로 아래에 담기 버튼 |
| all | 위 세 조건을 함께 적용 | 위 세 조건을 함께 개선 |

CTA는 위치 조건이다. 긴 페이지에서 아래로 스크롤하면 찾을 수 있다. 해당 사용자가 포기하는 확률까지 검증된 것은 아니다. 배송 지역은 성북·노원이며 입력 주소가 해당 지역인지 가볍게 확인한다. 실제 인증·결제·배송·계정 생성은 없다.

## 에이전트로 실행

```bash
python -m agent.cli --shop fixed
python -m agent.cli --shop problem --case signup
python -m agent.cli --shop problem --case cta
python -m agent.cli --shop problem --case fee
```

위 명령은 자체 임시 서버를 열고 두 세션을 실행한 뒤 서버를 종료한다. 기본 정책은 보이는 라벨을 따라 행동하는 고정 fixture다. 확장된 클릭·입력·체크·스크롤 실행 경로를 테스트하며, 실제 모델 추론 성능과 구분한다.

```bash
python -m agent.cli --shop fixed --policy openai --model YOUR_MODEL_ID
```

실제 모델은 `OPENAI_API_KEY`와 사용 가능한 모델 ID가 필요하다. 현재 API 호출은 미검증이다. 두 세션을 실행하므로 호출량과 예산을 확인한다.

현재 에이전트가 자동으로 이슈를 분류하는 것은 필수 입력 필드 예산 규칙이다. fee·cta는 UI 조건과 실행 경로만 검증했으며 해당 문제의 자동 분류기·실사용자 이탈 예측은 아직 없다. 판정에 맞춰 데이터를 꾸미지 않는다.

## 하네스 검증

```bash
python scripts/verify_harness.py --profile browser
```

[검증 명세](../harness/SPEC.md)와 [체크리스트](../harness/CHECKLIST.md)에 실제 테스트를 연결했다. 결과는 `artifacts/harness/<실행ID>/verdict.json`에 저장된다. 모델 없는 gate 통과는 실제 모델 호출 검증을 의미하지 않는다.

## 확장 과업 패널

DropSpot `http://localhost:4174/#personas`에서 과업을 고르거나 전체를 실행한다. 3개 프로필 × 4개 과업 = 12세션을 최대 3개씩 실행한다. 각 세션은 새 브라우저로 시작한다.

| 과업 | 정상 대조 | 마찰 포함 흐름 |
|---|---|---|
| 첫 주문 | 비회원 주문 | 가입 필수 입력 9개 |
| 배송 지역 확인 | 지역 1개만 입력 | 조회 전 개인정보 등 5개 입력 |
| 쿠폰으로 주문 | 쿠폰 바로 받기·배송비 사전 노출 | 긴 소개 아래 쿠폰·주문 후반 배송비 노출 |
| 다음 배송 건너뛰기 | 추가 정보 없이 한 번 건너뛰기 | 사유·연락처 등 5개 필수 입력 |

`/lab`에도 각 흐름의 직접 링크가 있다. 구독 관리 화면은 테스트용 모의 구독이며 로그인이나 실제 구독 변경이 없다. 배송 조회·쿠폰·건너뛰기 결과 경로는 필요한 세션 상태가 없으면 시작 화면으로 돌아간다.

좌절 v2는 관측한 필수 필드, 단계 재방문, 실제 탐색 스크롤, 보이는 늦은 배송비 경고에 초기 가중치를 적용한다. 같은 배송비 경고를 매 입력마다 다시 가산하지 않는다. 범용 UX 진단기나 실제 이탈률 예측기로 검증된 것이 아니다. 정상 대조에서 네 과업을 완료하고 마찰 포함 버전의 서로 다른 지점에서 중단하는 것은 로컬 브라우저 테스트로 검증한다.
