# 현재 브라우저 구성과 남은 검증

현재 채택한 연결은 Playwright 관찰/행동 + Skyvern 세션 API/공식 UI다. 설치 구성은 [연동 문서](../integrations/skyvern/README.md)를 참고한다.

- 실제 브라우저의 마우스 이동 이벤트로 커서 오버레이를 갱신한다. 사람의 움직임을 측정한 데이터는 아니다.
- 모든 세션은 작은 캡처로, 선택한 세션은 라이브 화면으로 표시한다. 50개 화면 재생은 별도 UI 예시다.
- 기본 검증은 외부 고객 사이트 없이 로컬 브라우저와 공급자 API 대역으로 실행한다.
- `scripts/verify_skyvern_live.py`는 별도 설치에서 실제 프레임/입력/세션 인계를 확인한다.
- 모델 자율 판단, 고객별 로그인 세션 인계, 운영 스트림 접근 제어, 50개 동시 실행은 별도 미검증이다.
